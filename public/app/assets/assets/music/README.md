# Musica de fondo

`fondo.mp3` es "Happy Vibes" de **Ruskerdax**, publicada en OpenGameArt bajo
**CC0 / dominio publico** (uso comercial, sin atribucion obligatoria):
https://opengameart.org/node/160228. Hecha con sintetizadores Roland, no con
IA. Convertida a MP3 mono 44.1 kHz a 96 kbps y nivelada a -20 LUFS con ffmpeg.

Opcional: `halloween_fondo.mp3`, bajo la misma regla. Si falta se usa la normal.
Ver ../sounds/LEEME.md.
